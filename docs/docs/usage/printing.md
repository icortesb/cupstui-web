# Printing

From the **Print** tab: `↑` `↓` moves between fields, `←` `→` changes the
value of the selected one, `ctrl+o` opens a file browser, `enter` sends the
job.

Fields cover copies, page ranges, duplex, colour and orientation.

Submitting jobs goes through `lp` rather than raw IPP — see
[How it works](/how-it-works) for why.
