# Keys

| Key | |
|---|---|
| `1`–`6`, `tab` | switch tab |
| `j` `k` | move |
| `/` | filter |
| `r` | refresh now |
| `?` | help |
| `T` | toggle transparent background |
| `S` | sign in to a remote server |
| `q` | quit |

**Queue** — `p` hold or release, `x` cancel, `X` cancel every job.

**Printers** — `e` enable or disable, `d` set as default, `a` accept or
reject jobs, `A` add, `x` remove, `u` quotas and access, `i` diagnose.

**Print** — `↑` `↓` change field, `←` `→` change value, `ctrl+o` browse
files, `enter` print. Copies, page ranges, duplex, colour and orientation.

**History** — `s` totals, `E` export CSV.

**Logs** — `n` next log, `v` minimum level, `G` jump to the end.
